What this compressor supports

Add up to 20 HEIC, JPEG, PNG, WebP, or AVIF images. Export each result as JPEG, WebP, PNG, or AVIF, then download files separately or together as a ZIP archive.

How local compression works

The browser decodes each source, optionally resizes it, and creates a new output. JPEG and WebP use quality-based encoding, PNG uses color quantization, and AVIF uses a local WebAssembly encoder.

Choosing an output format

Use JPEG for photographs and broad compatibility, WebP for efficient modern web images, PNG for transparency and interface graphics, or AVIF when the destination supports newer formats.

HEIC photos

HEIC and HEIF files are decoded locally before compression. The exported public copy can use a more widely accepted format without sending the original photo to a server.

Quality and target size

Start around 75% quality and set the largest width the destination needs. An optional target size makes several local encoding attempts and keeps the closest practical result.

Compare before downloading

Use the comparison slider on each completed image to inspect text, faces, product details, gradients, and sharp edges. File-size savings alone do not guarantee an acceptable result.

Privacy and metadata

Re-encoding creates a metadata-light copy, but compression does not hide visible private details. Redact secrets first and use the EXIF tool when metadata removal needs separate verification.

Frequently asked questions

Is the target size exact?
No. Image content and encoder limits affect the final size, so the tool reports the closest result it can produce without changing dimensions beyond your settings.

Does batch processing upload my files?
No. Processing and ZIP creation happen in the browser tab.
