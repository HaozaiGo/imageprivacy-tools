A practical image privacy workflow

ImagePrivacy is built around a simple idea: keep the original image private, then publish a smaller, cleaned, reviewed copy. Hidden metadata and visible content are different risks, so a good publishing workflow should check both before an image is shared in a support ticket, marketplace listing, portfolio, social post, or public document.

Hidden metadata

  • Inspect camera, software, time, and GPS-related fields.
  • Remove EXIF data before publishing public copies.
  • Keep the original file in private storage when you may need it later.

Visible private details

  • Look for faces, addresses, screens, IDs, and document text.
  • Redact areas that should not appear in the shared copy.
  • Use watermarks for proofs, previews, and ownership context.

Share-ready export

  • Resize images when full resolution is unnecessary.
  • Compress files for tickets, forms, and web publishing.
  • Convert HEIC, PNG, JPEG, or WebP into the format your platform accepts.

Before you publish an image

1. Review the picture

Zoom in and check the visible scene. Metadata cleanup will not hide screen text, addresses, faces, badges, invoices, or personal documents.

2. Create a public copy

Export a new image after redaction, watermarking, resizing, or conversion. Keep the source file separate and do not overwrite your private original.

3. Recheck the result

Open the exported file once more before uploading it. Confirm the visible content, dimensions, format, and file name are appropriate for the destination.

ImagePrivacy FAQ

What does ImagePrivacy help with?

It helps you prepare safer public copies of images by reducing hidden metadata, redacting visible details, adding watermarks, resizing, compressing, and converting formats.

Do the tools upload my files?

The tools are designed for browser-side processing. Your image should remain on your device while you create a new cleaned copy.

Does removing EXIF hide everything private?

No. EXIF removal reduces hidden metadata, but visible information inside the image still needs manual review and redaction when necessary.

Should I share the original image?

Usually no. Share a cleaned copy that has only the size, format, metadata, and visible details needed for the public context.
