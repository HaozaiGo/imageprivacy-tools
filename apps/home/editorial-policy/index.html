Editorial Policy

How ImagePrivacy maintains guidance.

Updated October 20, 2026. ImagePrivacy is independently maintained by HaozaiGo, the owner of the linked public GitHub projects.

Purpose

ImagePrivacy helps people prepare safer copies of images before sharing. Content must distinguish hidden metadata from visible details and explain what a browser tool can verify, what it changes, and what still requires human review.

Tool testing

The verification checklist describes suggested checks with harmless sample files. It is not a completed test report. Claims of a passed check should identify the tested version, browser, sample, observed result, and limitations. Functional checks do not certify complete HEIC support or exhaustive metadata removal.

Privacy verification

Browser-side image processing describes the intended file workflow, not an independent security audit or absence of network requests. Metadata readers have format and field limits. Guides distinguish source inspection, exported-file verification, and manual review of visible details; none should be presented as a universal privacy guarantee.

Guide standards

Guides use original workflows, practical checklists, and synthetic examples. Primary documentation is preferred for image formats, browser APIs, and privacy requirements. Content does not present a tool result as legal, copyright, or professional security advice.

Updates and corrections

A reviewed or updated date refers to content maintenance, not completion of every suggested test. Material changes are recorded in the public changelog. Readers can report inaccurate guidance, format problems, or inaccessible pages through the contact page.

Advertising independence

Advertising does not determine tool output, privacy conclusions, rankings, or guide coverage. Ads must remain distinguishable from uploads, editor controls, previews, reports, and downloads. ImagePrivacy does not accept payment to change a privacy result.
