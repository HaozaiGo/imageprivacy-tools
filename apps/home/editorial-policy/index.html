Editorial Policy

How ImagePrivacy tests tools and maintains guidance.

Reviewed September 8, 2026. ImagePrivacy is independently maintained by HaozaiGo, the owner of the linked public GitHub projects.

Purpose

ImagePrivacy helps people prepare safer copies of images before sharing. Content must distinguish hidden metadata from visible details and explain what a browser tool can verify, what it changes, and what still requires human review.

Tool testing

Tools are checked with newly created sample images that contain no private user data. Reviews cover supported formats, output dimensions, visual changes, metadata behavior, file download, language switching, browser compatibility, and mobile layout.

Privacy verification

Local-processing claims are checked with browser developer tools and controlled sample files. Metadata removal is verified against exported copies when the format allows inspection. A clean metadata result does not prove that faces, addresses, screens, or document text have been removed, so guides keep those checks separate.

Guide standards

Guides use original workflows, practical checklists, and synthetic examples. Primary documentation is preferred for image formats, browser APIs, and privacy requirements. Content does not present a tool result as legal, copyright, or professional security advice.

Updates and corrections

Pages include a reviewed or updated date. Material changes are recorded in the public changelog. Readers can report inaccurate guidance, format problems, or inaccessible pages through the contact page.

Advertising independence

Advertising does not determine tool output, privacy conclusions, rankings, or guide coverage. Ads must remain distinguishable from uploads, editor controls, previews, reports, and downloads. ImagePrivacy does not accept payment to change a privacy result.
